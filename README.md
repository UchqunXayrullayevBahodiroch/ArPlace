# AR Place — AR-примерка мебели (ARCore + SceneView)
Сборка APK: GitHub → вкладка Actions → Build APK → Artifacts → ARPlace-apk.
Модели лежат в app/src/main/assets/models/ (GLB). Новая модель: положить файл туда и добавить строку в CATALOG (MainActivity.kt).
Управление: тап по поверхности — поставить; перетаскивание — переместить; два пальца — поворот/масштаб; кнопки справа — масштаб, поворот, удаление, снимок.
